# IA-praxis

Proyecto de investigación y construcción de un sistema de IA modular, eficiente y medible.

## Objetivo

Explorar cuánto puede aumentar la capacidad práctica de un modelo relativamente pequeño mediante arquitectura de sistema: conocimiento externo, recuperación, memoria, razonamiento, planificación, herramientas y evaluación.

La primera especialización será **programación**, con **Python** como dominio inicial.

## Regla de ingeniería

Cada capacidad nueva deberá poder:

1. implementarse;
2. probarse;
3. medirse;
4. compararse contra una línea base;
5. documentarse;
6. evaluarse en recursos y limitaciones.

El proyecto evitará entrenar modelos desde cero mientras no exista evidencia experimental de que la arquitectura externa no sea suficiente para el objetivo estudiado.
